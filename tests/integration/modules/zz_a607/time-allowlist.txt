# A607: files allowed to read the REAL wall clock (Clock::real()/Clock::real_mysql()).
# Business rules (holds, deadlines, expiry, sales windows, reminders, retention cut-offs, validity,
# queue due times) use Clock::now()/Clock::mysql(), which follow the `wpcap_now` filter. Only
# infrastructure that must keep real time while `wpcap_now` is injected belongs here: cron
# scheduling, locks/leases, rate-limit and time-budget windows, signatures/timestamps exchanged with
# providers or devices, certificate expiry, log/monitoring timestamps, cache lifetimes.
# Raw time() / current_time( 'mysql', true ) is allowed in src/Clock.php only.
# Format: <path below src/>  # <reason>. Remove a line once the file no longer needs the real clock.
